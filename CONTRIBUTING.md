# Contributing

## Development

If you want to have the npm version and a dev version installed simultaneously, I can recommend simply installing a shell alias:

```bash
alias bndev="bun path-to-repo/src/cli.ts"
```

you can then run bndev instead of bn to test (note this will still use your real credentials).

To quickly create some testing projects, the astro cli is quite helpful>

```bash
pnpm create astro --template starlight
```
